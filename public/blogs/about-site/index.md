# 关于本站

欢迎来到我的个人网站。这里是陈鹳嫒的个人空间，用来记录我的学习、思考与生活。

## 内容板块

本站目前包含以下板块：

- **首页**：单页滚动展示，包含关于我、项目、博客、经历、荣誉、兴趣与联系方式
- **项目**：我参与或主导的项目展示，每个项目有独立的详情页
- **文章**：我撰写的一些文章，部分首发于微信公众号，部分为站内文章
- **关于**：更完整的个人介绍与经历

## 技术栈

本站基于以下技术构建：

- **Next.js 16** — React 全栈框架
- **Tailwind CSS 4** — 样式系统，支持深色 / 浅色模式自动切换
- **Motion** — 页面动效与滚动动画
- **Shiki** — 代码高亮
- **KaTeX** — 数学公式渲染
- **GitHub Pages** — 静态托管与自动部署

站点采用静态导出（`output: 'export'`）模式，构建后直接部署到 GitHub Pages，加载快速、无需服务器。

## 文章说明

「文章」板块中的部分文章首发于微信公众号，点击卡片会直接跳转到原文；站内文章则可在站内直接阅读。
